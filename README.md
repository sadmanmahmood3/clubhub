# ClubHub: IUB Club & Event Management System

ClubHub is a web application that brings club and event activity at IUB into one place.
Students find clubs, join them and register for events; club executives create events;
DOSA (Division of Student Activities) approves them.

CSE 451 Software Engineering group project, Autumn 2026.
